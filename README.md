## 打开方式

双击 `index.html` 即可在浏览器中打开。

## 页面功能

- 查看个人基本信息、求职意向、专业技能
- 查看项目经历与校园实践经历
- 一键复制邮箱
- 下载简历PDF
- 导航栏平滑滚动
- 手机端自适应显示

## 部署到 Gitee Pages（第5册上线用）

1. 在 Gitee 新建仓库，把本文件夹内所有文件上传（保持 `index.html` 在仓库根目录）
2. 仓库 → 服务 → Gitee Pages → 选择部署分支
3. 开启后得到 `https://你的用户名.gitee.io/仓库名/`，可写进简历
> 代码已用相对路径、无外部CDN，部署后图片和下载按钮都会正常。
